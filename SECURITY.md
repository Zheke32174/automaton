# Security Policy

## Reporting a Vulnerability

This repository contains the Conway Automaton sovereign AI agent runtime.
If you discover a security-relevant issue (identity, financial, or code execution),
contact the repository maintainers directly. Do not open a public issue.

## Scope

In-scope:
- Agent identity and authentication bypass
- Financial/spending logic vulnerabilities
- Code execution in agent tooling
- Data layer injection or leakage
- Supply chain risks in dependencies

Out-of-scope:
- Theoretical attacks without practical exploit path
- Issues in upstream dependencies already reported

## Expectations

Security patches will be addressed per the regular release cycle.
This is a research project operating under the Pleiades Factory
lightning-round process.
